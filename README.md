# One Line, Zero Use: The Useless Superpower Sprint

A single original line naming a hilariously useless superpower: the gift of calling down lightning from a clear blue sky — with one small, fatal catch that makes the power exactly as useful as it sounds. Written for the make.fun bounty "One Line, Zero Use: The Useless Superpower Sprint", where a deadpan comedy judge compares one-liners pairwise on funniness, freshness, and tight wording.
